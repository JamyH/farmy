Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: Farmy is applying for this program. Until a release says otherwise in its notes, it is not signed yet and Windows SmartScreen may warn.

What gets signed

Only the two files of a release: Farmy-Setup-x.y.z.exe and Farmy-x.y.z-portable.exe. Both are built from the public source code by a GitHub Actions workflow on GitHub-hosted runners. Upstream components inside them, such as Electron, are not signed by this project.

Privacy

Farmy has no account, no tracking and no telemetry. Your game data, Riot ID and match history stay on your PC. The app reads League's local interfaces and small regions of your screen, and it loads public game data from the services below. Where a request needs one, it contains only the champion and role. Like every web request, it also shows your IP address to that service.
